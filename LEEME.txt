Producción: Netlify + Supabase
Página pública: /
Panel privado: /admin

La publicación se configura usando netlify.toml. El panel inicia sesión mediante funciones de Netlify y los servicios se guardan en Supabase.

Para configurar todo, seguí NETLIFY_SUPABASE_SETUP.md y ejecutá supabase/setup.sql desde el SQL Editor de Supabase.

Nunca publiques .env ni la clave secreta de Supabase. Las credenciales privadas se configuran directamente en las variables de entorno de Netlify.

El servidor server.js se conserva como forma de prueba local antigua; no es el backend que utiliza la publicación Netlify. La publicación usa netlify/functions y la base de datos Supabase.
